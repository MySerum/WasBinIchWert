# WasBinIchWert

## Entwicklung

Die automatisierten Referenz- und Offline-Tests werden mit folgendem Befehl ausgeführt:

```bash
npm test
```

Die Tests benötigen keine Netzwerkverbindung und prüfen die lokale Steuerengine,
die Sozialversicherungs-Referenzwerte sowie die Vollständigkeit des Offline-Caches.
